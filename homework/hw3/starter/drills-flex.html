Flexbox drills

Nine containers. Each one needs Tailwind classes added to the element marked <!-- YOUR CLASSES --> so the boxes land where the goal says. Edit this file in VS Code, save, reload the page. The checks below grade themselves.

Do this file in VS Code, not in Tailwind Play. Play takes a snippet of markup; this is a whole document with a checking script, so the counter will not run there. Open the homework/hw3/ folder in VS Code, then right-click this file → Open with Live Server and put the editor and the browser side by side.

Read this first

Open Tailwind docs — justify-content and spend two minutes on it before drill 1. Every Tailwind class has a page laid out the same way: a table of every class and the exact CSS it compiles to, then a live example, then a note on using it at a breakpoint.

Once you can read one of these pages you can answer every drill below from the documentation rather than from memory — which is the habit worth taking out of this assignment. Each drill links the page it needs.

1. Make it a row

docs: display

The boxes are stacked because a div is a block. Put them in a row.

2. Push them to the centre

docs: justify-content

Keep the row. Group all three in the middle of the container.

3. First left, last right

docs: justify-content

One box hard against each end, the third spaced evenly between. This is the header from Task 1.

4. Equal space around each one

docs: justify-content

Every box gets the same amount of space on both of its sides. Not the same as drill 3 — look closely at the ends.

5. Line up the middles

docs: align-items

The boxes are different heights. Put them all on one invisible middle line.

6. Put space between them

docs: gap

The boxes are touching. Separate them without adding a margin to any box. Flexbox Froggy never teaches this one — it is newer than the game.

7. Turn the row into a column

docs: flex-direction

Same container, stacked top to bottom instead of left to right.

8. Now the axes have swapped

docs: align-items

Keep it a column, and centre the boxes horizontally. Careful: in a column, items-* is the horizontal one.

9. Dead centre

docs: justify-content

One box, centred both ways. Two classes on the container.

When all nine pass, you have everything Task 1 of the homework needs. Next: the grid drills.
