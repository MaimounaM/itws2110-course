# Included component source

`src/components/ui/button.jsx`, `card.jsx`, and `input.jsx`, `src/lib/utils.js`,
and the theme in `src/index.css` were generated with the official shadcn/ui CLI
4.21.0 using the Radix base, Nova preset, JavaScript output, and Tailwind 4.
They are supplied so the class can reach drill 11 without a live registry request.

Upstream: [shadcn/ui](https://github.com/shadcn-ui/ui), MIT license; see
[SHADCN-LICENSE.md](SHADCN-LICENSE.md). Other installed dependencies retain their
own licenses in their packages. `package-lock.json` records resolved versions.

The workshop-specific components in `drills.jsx` and `capstone.jsx` demonstrate
how to use these building blocks. Generated component internals are reading material
at the end of the lab, not something students need to recreate before drill 1.
