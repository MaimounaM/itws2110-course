# React — start small

[← In-class activities](../README.md)

The next step after [Homework 3's Tailwind drills](../../homework/hw3/README.md):
keep the familiar classes, and use React to generate and update the elements.

Start at **[the React workshop](react/README.md)**. It includes a one-file
micro-installation, eleven small drills with browser checks, worked answers, a
final example combining your own component with shadcn/ui, and four more drills
that write component tests with Vitest and Testing Library.

Suggested pacing: micro-installation and drills 1–6 in the first session; drills
7–11 in the next; drills 12–15 in **session 11 (Fri 10/2)**, the one that sets up
Homework 5. These are practice examples, with no new submission or grading requirement.
