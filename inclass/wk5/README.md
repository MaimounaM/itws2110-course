# React — start small

[← In-class activities](../README.md)

The next step after [Homework 3's Tailwind drills](../../homework/hw3/README.md):
keep the familiar classes, and use React to generate and update the elements.

Start at **[the React workshop](react/README.md)**. It includes a one-file
micro-installation, eleven small drills with browser checks, worked answers, and a
final example combining your own component with shadcn/ui.

Suggested pacing: micro-installation and drills 1–6 in the first session; drills
7–11 in the next. These are practice examples, with no submission or grading
requirement. Week 6 continues in [`../wk6/`](../wk6/README.md).
