# React — where state lives, and how to prove it

[← In-class activities](../README.md)

Week 5 built components and gave them state. Week 6 asks where that state should live,
then writes tests that check a component the way a person would.

Start at **[the week 6 workshop](react/README.md)**: four drills on where state lives (keys,
lifting state, derived state, composition), checked in the browser, and four
that write component tests with Vitest and Testing Library, checked in the terminal.
It's a new folder, so it needs its own `npm ci`.

**Hand-in: push your copy of the workshop to your own repository at the end of class** —
with whatever you got through. Unfinished drills are fine; it counts toward participation,
not correctness.

Copy the `react` folder from `inclass/wk6/` in the course repo and paste it into
`inclass/wk6/` in your own repository (Finder or Explorer is fine), then commit and push.
Leave `node_modules` behind if you can — your `.gitignore` keeps it out of the push either
way. Kept going after class? Copy, paste and push again — the latest push counts.
