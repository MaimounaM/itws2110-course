# Eloquent — models, migrations, relationships

[← In-class activities](../README.md)

Until now the pantry's data was typed into the code. This week it moves into a database,
and the framework's ORM, Eloquent, turns its rows into objects.

Start at **[the week 9 workshop](laravel/README.md)**: twelve drills in a Laravel app with a
MySQL database, run with `docker compose watch`. Drills 1–5 are migrations and models;
6–9 are relationships; 10–12 make a model of your own, from `php artisan make:model`. Each has a **Check result** button on the drills page. Build it
before class — the first run downloads PHP, MySQL and Laravel's packages.

**Hand-in: push your copy of the workshop to your own repository at the end of class** —
with whatever you got through. Unfinished drills are fine; it counts toward participation,
not correctness.

Copy the `laravel` folder from `inclass/wk9/` in the course repo and paste it into
`inclass/wk9/` in your own repository (Finder or Explorer is fine), then commit and push.
Kept going after class? Copy, paste and push again — the latest push counts.
