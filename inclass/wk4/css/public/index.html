One page, five ways

The same Pantry page — same HTML content, same data — styled five different ways. Open them in order. Each folder's index.html is the whole thing.

  1. 0 — Plain CSS, and the problem: every rule is global
  2. 1 — BEM: names that say what a thing is
  3. 2 — Bootstrap: components someone else designed
  4. 3 — Tailwind: names that say what a thing looks like
  5. 4 — Responsive: the same page on a phone
